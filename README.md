# Faisal Khan — Portfolio

Personal portfolio. Static site (no build step), hosted on Vercel.

- **Live:** https://ifaisalk-portfolio.vercel.app
- **Stack:** hand-written HTML / CSS / vanilla JS, set in IBM Plex
- **Structure:**
  - `index.html` — the page
  - `assets/style.css` — styles
  - `assets/script.js` — interactions (reveal, nav, clock, copy)
  - `assets/portrait.png`, `assets/favicon.svg`
  - `Faisal-Khan-Resume.pdf`

Edit the files and `vercel deploy --prod` (or push, once Git is connected) to publish.
